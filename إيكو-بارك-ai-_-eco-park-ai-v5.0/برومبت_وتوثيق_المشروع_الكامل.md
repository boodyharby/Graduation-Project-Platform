# 🌿 إيكو-بارك AI (Eco-Park AI v5.0 Master Edition)
## المرجع المعماري والتوثيق الشامل

### 1. الرؤية المعمارية في بيئة التشغيل السحابية
يعمل التطبيق الحي (React 19 + TypeScript + Vite + Three.js + Firebase + Express Server على المنفذ 3000) مباشرة من الجذر عبر `server.ts` ومجلد `src/` لضمان تكامل الواجهة والخادم واستدعاءات Gemini API الآمنة على الخادم (`process.env.GEMINI_API_KEY` عبر **Settings > Secrets**).

### 2. شجرة المكونات الأساسية
- `server.ts`: خادم Express لخدمة Vite/SPA ومسارات Gemini API الآمنة (`/api/copilot`, `/api/tts`, `/api/anpr`, `/api/gemini/status`).
- `src/main.tsx` و`src/index.css` و`src/App.tsx`: نواة تطبيق React SPA وإدارة لوحة التحكم، الحجوزات، الطاقة BESS/V2G، والمستخدمين RBAC.
- `src/types/parking.ts`: واجهات TypeScript الكاملة للمواقف، التذاكر، المعاملات، والأدوار.
- `src/utils/ecoEngine.ts`: محرك حسابات الكربون ESG Scope 3، مؤشرات الحرارة، صافرة الإنذار الصناعية (`Web Audio API`)، ومذيع تحذيرات الأمان الصوتي.
- `src/components/Simulator2D.tsx`: المحاكي ثنائي الأبعاد مع طبقة الخريطة الحرارية المرتبطة بالإشغال.
- `src/components/Simulator3D.tsx`: المحاكي ثلاثي الأبعاد Three.js مع خوارزمية التوسع التلقائي للمواقف عند الامتلاء.
- `src/components/CopilotDrawer.tsx`: مساعد Gemini AI الناطق لإعطاء نصائح بيئية واقعية وتنفيذ الأوامر الحية.
- `backend/` و`frontend/`: الملفات المصاحبة للنسخة المحلية المستقلة (Python/SQLite + Vanilla HTML5).
