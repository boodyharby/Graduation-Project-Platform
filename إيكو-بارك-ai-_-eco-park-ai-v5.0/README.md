# 🌿 إيكو-بارك AI (Eco-Park AI v5.0 Master Edition)

منظومة ذكية لإدارة مواقف السيارات المستدامة وخفض البصمة الكربونية وفق معايير **ESG Scope 3** ومبادرة **السعودية الخضراء**.

## المميزات الأساسية
1. **التعرفة الديناميكية الخضراء ومحفظة الكربون**: إعفاء 100% للمركبات الكهربائية + نقاط كربون، وخصم للهجين، وضريبة تشجير للديزل.
2. **بطاريات BESS وتبادل الطاقة الثنائي V2G**: مراقبة مستوى الشحن مع **صافرة إنذار صناعية واقعية (Web Audio API)** عند انخفاض الشحن عن 20% وإعلان صوتي احترافي لتحذيرات الأمان.
3. **المحاكي ثنائي الأبعاد (`Simulator2D`)**: مسار توجيه كربوني، طبقة خريطة حرارية مرتبطة بالإشغال الفعلي، ونظام رذاذ تبريد مائي.
4. **المحاكي ثلاثي الأبعاد (`Simulator3D`)**: مشهد Three.js بمواد PBR، إضاءة نهارية/غروب/ليلية، وخوارزمية **Dynamic Bay Expansion** لإنشاء موقف جديد تلقائياً عند امتلاء الساحة.
5. **مساعد Gemini AI Copilot الناطق (`CopilotDrawer`)**: محادثة ذكية متعددة الأدوار تعطي نصائح بيئية واقعية بناءً على القراءات الحية، مع نطق صوتي احترافي عبر الخادم (`/api/copilot` و`/api/tts`) وإدخال بالمايكروفون.

## التشغيل السريع (النسخة الحية React + Express + Firebase)
- يتم إدارة مفتاح `GEMINI_API_KEY` بأمان على الخادم عبر **Settings > Secrets**.
- لتشغيل بيئة التطوير على المنفذ `3000`:
```bash
npm install
npm run dev
```

## ملفات الهيكل المعماري المصاحبة
- `backend/`: خادم Python REST API اختياري (`server.py`، `ai_model.py`، `schema.sql`).
- `frontend/`: واجهة HTML5/CSS/JS مستقلة (`index.html`، `style.css`، `app.js`).
- `تشغيل_المشروع.sh` / `run_project.bat`: سكريبتات تشغيل سريعة.
